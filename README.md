# lezzetapp


## Description
 welcome to Lezzet App  a simple Flutter application that allows users to explore and search for restaurants based on different world cuisines. The app provides an easy way to discover food from various cultures run by local or foreign chef  of those country with a clean and user-friendly interface.

---

##  Features
-  Search restaurants by food type
- Explore different world cuisines
-  Simple and clean user interface
-  Navigation between multiple pages (Welcome, Search, Food)

---

- Dart

## ▶️ How to Run the Project 
1. Clone the repository:

git clone https://github.com/aicha1705/flutter_midproj.git


2. Navigate to the project folder:

cd flutter_midproj


3. Install dependencies:

flutter pub get


4. Run the app:

flutter run
